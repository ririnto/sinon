# Implement

Complete the requested change with the minimum sufficient edit.
Use the [shared engineering rules](../../docs/rules.md) for instruction discovery, authority, planning, proof, and completion.
From their index, load language guidance for changed source and tool guidance for affected build or validation profiles.
Read design, interface, and test-quality sections when those surfaces change.

## Implementation

Read the affected code, callers, tests, configuration, and types before choosing the change.
For non-trivial work, reuse or make a self-contained plan with outcome, scope, affected files, and proof.
Fix the root cause, then review the diff against the task and applicable rules.
Continue through the required checks and authorized Git handoff instead of stopping at the first implementation.
Report the outcome, changed paths, evidence, and remaining gaps in the task's required format.
