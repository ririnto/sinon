# Optional Product Spec Example

Use this file to document an onboarding flow.
Replace it with a project-specific product spec, rename it to the feature it describes, or remove it when it does not apply.

## Purpose

Show the shape a product spec takes under `docs/product-specs/`: target user, acceptance criteria, and references to the related design doc or exec plan.

## When To Update

Update when the spec describes a feature whose scope, success criteria, or acceptance gate changes.
Delete the file when the feature ships and is folded into general product documentation.

## Required Evidence

- Cite the user research, PRD, or stakeholder decision that motivates the spec.
- Link the related entry under `docs/exec-plans/` while the work is in flight.
