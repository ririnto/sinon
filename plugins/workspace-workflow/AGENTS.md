# Repository Guidelines

This file applies to `plugins/workspace-workflow/` and overrides broader plugin guidance.

## Project Structure

`skills/pr-mr-convention/` owns host-neutral publication guidance and host references. Agents draft or route work; they do not publish.

## Build, Test, and Development Commands

Inspect `git remote -v`, `git status --short --branch`, and `git branch -vv` before host advice.

## Coding Style and Testing

Select a host from explicit user choice, existing review metadata, policy, upstream, then remote evidence. If GitHub and GitLab remain plausible, ask for a choice. Load only the selected host reference and preserve an applicable repository template.

## Commit and Publication

Treat force-push and history rewriting as explicit user decisions.

## Security and Configuration

Report stale remote data and template uncertainty. Do not expose credentials or run host authentication checks before host selection.

## Scope and Precedence

Open the selected host reference only after selection. This file stays host-neutral; GitHub and GitLab command syntax belongs in their separate references. A repository's own review policy overrides this package guidance.
State which host evidence selected before drafting publication guidance.
