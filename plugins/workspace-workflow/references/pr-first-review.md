# PR-First Review

Remote publication requires separate authorization.
Never push directly to protected branches or the named base branch.

When remote publication is separately authorized, push the feature branch and open or update its pull request before independent review.
Complete an independent review of the complete posted change.
Ensure all required checks pass and resolve all acceptance blockers before normal integration.
Review completion and passing checks do not authorize normal integration.
Confirm the integration grant and follow the selected repository merge strategy.
